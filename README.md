# Method-Level Defect Prediction and Refactoring Analysis
This repository contains the final project developed for the course "Ingegneria del Software 2" of the University of Rome Tor Vergata (faculty Computer Engineering).

## Analyzed Projects
The analysis was conducted on the following Apache projects:
- Apache BookKeeper
- Apache OpenJPA

## Project Objectives
The project aims to:
- build method-level defect prediction datasets;
- compare different classifiers using Weka;
- identify actionable features correlated with bugginess;
- apply refactoring to a real method;
- estimate how many buggy methods could have been avoided
  if code smells had been removed.
